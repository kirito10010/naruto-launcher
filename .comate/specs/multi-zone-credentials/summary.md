# 同一 QQ 多区服凭证 完成总结

## 已实现
- 账号新增 `credentials`（按 `zone_id` 保存凭证）和 `lastZoneId`；保留旧 `credential` 兼容。
- 加载 `accounts.json` 时自动迁移：旧单凭证放进 `credentials[zone_id]`，补 `lastZoneId`。
- 凭证抓取按 `zone_id` upsert：同区反复登录只更新，`lastZoneId` 跟随最后进入的区。
- 新增 IPC：
  - `set-account-zone(accountId, zoneId)`：保存当前选择的区。
  - `clear-credential(accountId, zoneId)`：按区清凭证；无 zoneId 时清全部。
- 启动路径按区选凭证：
  - 游戏窗口侧边栏开窗、启动全部账号。
  - 主进程全局账号启动/一键启动/新建窗口。
  - 多区账号标签名：`窗口名/QQ · 区服名`。
- 账号栏 UI：
  - 多区显示区服下拉（区服名 + 有效/过期/无），切换即保存。
  - 单区显示区服文本，不增加操作。
  - 状态按当前选中区显示；清除按钮只清当前区，区服项保留为“凭证：无”。
  - 点下拉/区服行不会误触发“填充账号”。
- 凭证过期时仍打开该区的 `login_url`（而不是只打开官网首页），重新登录后自动补回该区。
- 修改账号 QQ 时清空旧区凭证，避免串号。

## 手工验收建议
1. 托盘右键退出当前测试实例，双击 `启动测试.vbs` 重新加载。
2. 同一 QQ 登录两个不同区，账号栏应出现区服下拉，两个区各自显示有效期。
3. 选 1098 → 开窗，标签名带 `· 1098区`，直接进 1098；再选 1099 → 开窗，另一个标签进 1099。
4. 切换下拉后直接点开窗，应使用新选中的区。
5. 清除当前区凭证：下拉里该区变为“凭证：无”，不会回退到其它区；重新登录后自动恢复。
6. 过期区：点开窗进入该区登录页，登录后有效期刷新。
7. 单区旧账号：不显示下拉，行为与之前一致。

## 注意
同一 QQ 同时在线多个区是否允许由游戏服务端决定；客户端只用对应区凭证登录，不会主动限制。
