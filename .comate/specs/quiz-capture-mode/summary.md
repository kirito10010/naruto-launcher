## 2. 实现要点

- **不需要 CDP 抓包**，只用 net-log（`CAPTURE_MODE !== 'off'` 时已自动开启）。
- 退出走托盘「退出」→ `before-quit` 拉起 `--export-quiz` 独立子进程 → 等主进程退出、netlog 写完 → 解析 → 写文件。
- 输出：桌面 `火影题库/忍者检测_<yyyy-MM-dd_HHmmss>.json`（UTF-8、2 空格缩进），并 `shell.showItemInFolder` 高亮文件。
- JSON 顶层为数组，每条 `{ question, options[], answer }`；`answer` 存**选项原文**（不是 A/B/C/D），答错 / 无对错标志 / 下标越界时为 `""`。
- 同一次抓包内按题面去重，优先保留有 `answer` 的记录。

## 3. 过程中发现并修正的问题

上行与下行帧**都经过 TEA 加密**（下行 type=2、上行 type=1，加密方式一致）。最初按「上行是明文」直接 `pb(payload)`，导致 `RangeError: offset out of range`；改为上下行统一走 `dec(cmd, payload)` 后正常。
