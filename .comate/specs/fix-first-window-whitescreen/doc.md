# 首次打开游戏窗口白屏修复方案

## 1. 背景与问题

首次启动后打开第一个游戏窗口，整个窗口（含顶部工具栏）全白，需要关闭窗口再重新打开才正常。后续窗口正常。

## 2. 根因分析

`createGameWindow` 用 `show: true` 立即显示窗口，且 `backgroundColor: '#ffffff'`。

首次启动时 GPU 进程、渲染进程冷启动较慢，窗口在 game.html 尚未渲染出第一帧前就以白色背景显示出来，表现为整窗白屏。第二次打开时进程已预热，渲染及时，因此正常。

## 3. 修复方案（main.js）

1. `BrowserWindow` 选项 `show: true` 改为 `show: false`。
2. 监听 `ready-to-show` 事件，首帧渲染完成后调用 `win.show()`。
3. 增加超时兜底：若 5 秒内未触发 `ready-to-show`，强制显示，避免窗口永远隐藏。

## 4. 受影响文件

| 文件 | 修改类型 | 位置 |
|------|----------|------|
| `main.js` | 修改 | `createGameWindow` 函数 |

## 5. 边界条件与异常处理

- 超时兜底保证 `ready-to-show` 异常时不至于窗口不可见。
- `win.isDestroyed()` 判断避免窗口已关闭后调用 `show()` 报错。

## 6. 预期结果

- 首次打开游戏窗口不再白屏，窗口出现时工具栏已渲染完成。
- 不影响多开、拉伸模式、变速等既有功能。
