# 在线人数数据可视化平台

## 需求

1. 现有在线人数后台（`server-app`）继续提供虚拟人数/显示人数。
2. 每 10 分钟统计一次人数，保存历史。
3. 统计启动器版本，展示每个版本有多少用户在使用。
4. 提供远程可访问的数据可视化页面，无需登录。
5. 端口优先 10001，被占用时自动使用 10002。

## 方案

### 数据采集
- 启动器 `online.js` 在每 5 秒的 `/report` 中增加 `version`（`CURRENT_VERSION`）。
- 服务端 `/report` 保存 `{ id, fire, mini, version, ts }`；旧版启动器不带 version 时记为 `unknown`。
- 当前在线版本分布：按 `clients` 逐个统计。
- 10 分钟活跃版本分布：按当前 10 分钟桶内出现过的唯一 `id` 统计。

### 10 分钟快照与按月存储
- 以 `Math.floor(Date.now() / 600000)` 为桶，每 15 秒检查一次边界。
- 每个边界生成一条快照：
  - `uniqueClients` / `uniqueVersions`：该 10 分钟内出现过的唯一客户端及版本；
  - `clients` / `versions`：快照时刻的在线客户端及版本；
  - `fire` / `mini`：显示人数与实际人数。
- 数据按月分文件：
  - 当前月 + 前两个月：`%APPDATA%\hyol-online-server\stats\YYYY-MM.json`，启动时加载；
  - 更早月份：自动移到 `stats\archive\YYYY-MM.json`，默认不加载；
  - 每个文件结构：`{ version:1, month:'2026-11', snapshots:[...] }`。
- 旧版单文件 `stats.json` 首次启动自动按月份拆分，成功后改名为 `stats.json.migrated` 并写 `.legacy-migrated` 标记。
- 只有仪表盘点「全部历史」时才按需读取 archive，读完不常驻内存。

### 数据面板
- `GET /` 或 `/dashboard` 返回 `dashboard.html`，无需登录。
- 页面内容：
  - 当前在线客户端、10 分钟活跃；
  - 火影/4399 显示人数与实际人数；
  - 当前在线版本分布（当前 + 10 分钟活跃）；
  - 最近 20 条 10 分钟快照表；
  - 24 小时 / 7 天 / 30 天趋势图（纯 SVG，无外部依赖）；
  - 「全部历史」按钮：按需读取仓库月份，不自动定时重扫。
- 页面每 10 秒刷新概览、每 60 秒刷新历史。

### API
| 路径 | 说明 |
| --- | --- |
| `POST /report` | 启动器上报，新增 `version` 字段 |
| `GET /stats` | 兼容启动器的在线人数 JSON |
| `GET /health` | 健康检查 |
| `GET /api/overview` | 当前在线、版本分布、最近快照 |
| `GET /api/history?hours=24` | 当前 3 个月内的历史，最多抽稀到 720 点 |
| `GET /api/history?all=1` | 按需读取 active + archive 全部月份，不常驻内存 |

### 端口
- 只监听 `10001`，上报接口和数据面板共用这一个端口：
  - 启动器 `POST /report` 上报；
  - 浏览器 `GET /` 看面板。
- 10001 被占用时不再自动切 10002，直接提示「请先退出旧版在线人数后台」。否则旧服务占着 10001，启动器继续上报旧服务，新面板会统计不到。
- 10002 仅作为人工备选，不在代码里自动启用。

## 边界与异常

- 旧版启动器无 version → `unknown`，面板显示「旧版/未知」。
- 没有快照时图表显示空状态；不影响当前在线数据。
- `stats` 目录损坏 → 忽略并重新开始，不影响服务。
- 旧版 `stats.json` 迁移失败 → 保留原文件，不写标记，下次启动重试。
- 归档文件默认不加载；只有点「全部历史」才读取，避免长期运行内存/启动变慢。
- 端口 10001 被占用 → 面板显示启动失败原因，提示先退出旧后台；不会自动切 10002。
- 面板无鉴权，按需求开放；建议仅在需要时开放防火墙端口。
- 数据目录：`%APPDATA%\hyol-online-server\stats\`，`archive\` 为历史仓库；以后升级保持该结构即可直接沿用。

## 预期结果

- 浏览器访问 `http://服务器IP:10001/` 即可看实时人数、版本分布和 10 分钟趋势；上报和面板共用 10001。
- 每 10 分钟自动落盘一条快照，重启服务后历史仍在。
- 2.1.0 及以上启动器能上报版本；2.0.0 及更早显示为「旧版/未知」。
