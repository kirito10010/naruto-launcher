# 拉伸模式下拖动窗口画面跳动修复方案

## 1. 背景与问题

拉伸模式开启后画面能正确铺满窗口，但在拉伸模式下**拖动（调整）窗口**时画面出现异常（在铺满与原生大小之间来回跳动）。

## 2. 根因分析

拉伸注入 JS 的 `doStretch()` 使用 `getBoundingClientRect()` 测量 Flash 元素尺寸。该 API 返回的是**包含 CSS transform 后的包围盒**，导致测量值被上一次缩放污染：

1. 首次：元素原生 1280×720 → `sx=sy=2` → 铺满。
2. 拖动窗口触发 `resize`：量到已放大后的 2560×1440 → `sx=sy=1` → 缩回原生。
3. 再次 `resize`：量回 1280×720 → 又放大。

拖动窗口会连续触发多次 `resize`，于是画面反复跳动。

## 3. 修复方案（仅 game.html）

1. 测量改用 `offsetWidth` / `offsetHeight`（布局尺寸，不受 transform 影响），消除反馈回路。
2. 用每秒一次（1000ms）的 `setInterval(doStretch)` 替代原先「仅元素缺失时轮询」的逻辑，兜底处理元素尺寸变化/晚出现。
3. 关闭拉伸时同步 `clearInterval` 清理定时器。

## 4. 受影响文件

| 文件 | 修改类型 | 位置 |
|------|----------|------|
| `game.html` | 修改 | `STRETCH_ENABLE_JS` / `STRETCH_DISABLE_JS` 常量 |

## 5. 预期结果

- 拉伸模式下拖动/最大化/全屏窗口，画面实时、稳定地跟随窗口尺寸填充，不再跳动。
- 关闭拉伸后正常恢复，无残留定时器与监听。
