# 账号侧边栏卡片改版 - 完成总结

## 改动内容（仅 game.html）

- 卡片改为块级布局：区服名做标题、QQ 做副标题、状态一行、操作一行。
- QQ 不再重复出现；自定义窗口名作为右侧小标签显示（等于 QQ 或区服时不显示）。
- 凭证状态改为"圆点 + 短文案"：
  - 未保存凭证（灰）
  - 已保存（约 24 小时）（黄）
  - 有效 N 天 / N 小时（绿）
  - 已失效，需重新登录（红）
- 4 个操作从 2×2 图标网格改为常驻的文字按钮：进入 / 清凭证 / 编辑 / 删除；"进入"使用主题强调色。
- 多区老账号的区服下拉移到标题位置，无边框，不再单独占一行。
- 清理了不再使用的 `.account-sidebar-info`、`.account-sidebar-zone` 样式和点击判断。

实现时把文档里的"清理"改成了"清凭证"，避免和"清理缓存"混淆；按钮 title 为"清除当前区服凭证"。

## 验证

- 用临时 Electron 预览页加载真实 game.html，注入 5 种账号（有效 / 已保存 / 已失效 / 无凭证 / 多区老数据），浅色与暗夜主题各截图一次：
  - 卡片层级、状态颜色、按钮布局正常；
  - 无凭证卡片自动少一个按钮；
  - 多区下拉正常显示。
- game.html 内联脚本 `node --check` 通过。
- 未打包，版本仍为 2.1.0。

## 后续调整

- 凭证剩余时间不再显示具体天数（cookie 到期只是上限，服务端可能提前作废，显示"6 天"会误导）。
- 状态改为标题行右上角的小圆点：绿=已保存且未过期、黄=已保存但无真实到期时间、红=已失效、灰=未保存凭证。
- 完整说明（含"以实际登录状态为准"和上次续期时间）放在圆点的悬停提示里，不占卡片行高。
