# 喵问答零错误答案推导 · 完成总结

## 实现内容

1. **解析 4 个 NPC**：题目对象的 `f7` 取出 `{ id, 站圈 ans, 累计分 score }`，挂在题库条目上（内部字段，不写入 JSON）。
2. **来源 A（主力）**：对比相邻两题同一 NPC 的累计分。
   - 增量必须恰好是 0 或 +10，其它值整题放弃；
   - 所有 +10 的 NPC 必须指向同一个圈，出现分歧整题放弃；
   - 推导结果等于「被排除的错误选项」时放弃。
   - 实测：20 题全部增量为 0/10，0 次分歧。
3. **来源 B**：我方提交下标 + 下行 `f5=1`；下标越界或等于排除项时放弃。
4. **冲突处理**：A、B 同时存在且不一致 → 答案留空，并写 `miao-export.log`。
5. **本地答案库**：`%APPDATA%\naruto-online-launcher\quiz-answers.json`，题干 → 答案原文。
   - 只写入有证据的答案；
   - 本轮无证据时按原文在当前选项里匹配（选项顺序变了也能命中）；
   - 文件损坏/写入失败静默降级。
6. 导出字段保持 5 个：`question / options / answer / removed / image`。
