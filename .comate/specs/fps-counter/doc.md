# 游戏 FPS 实时显示功能方案

## 1. 背景与目标

用户想知道游戏实际帧率，希望有一个可开关的 FPS 显示，且不担心影响流畅度。

目标：工具栏新增「FPS」开关，开启后在游戏画面角落实时显示帧率，关闭后消失，可随时切换。

## 2. 帧率说明

火影忍者Online 是 Flash 页游，SWF 原生帧率一般在 24~30，具体值由游戏内部定义。本功能用 `requestAnimationFrame` 测量**实际显示/合成帧率**（即用户感知的流畅度），实时显示。

## 3. 技术方案

- 工具栏新增 `btn-fps` 开关（默认关闭，不持久化）。
- 开启：向 webview 注入 JS —— 创建右上角小浮层（`position: fixed`），用 `requestAnimationFrame` 每秒统计帧数，每秒更新一次文本（如 `60 FPS`）。
- 关闭：`cancelAnimationFrame` 停止计数 + 移除浮层，零残留。
- 多标签：遍历当前窗口所有标签的 webview 统一应用/移除；`did-stop-loading` 时若开启则重新注入（应对导航/刷新丢失）。

## 4. 性能影响

几乎为零：`requestAnimationFrame` 是渲染进程本来就运行的循环，仅多一次计数；每秒只更新一个文本节点，不会触发整页重绘。关闭后彻底移除监听与 DOM，无任何开销，**不影响游戏流畅度**。

## 5. 受影响文件

| 文件 | 修改类型 | 位置 |
|------|----------|------|
| `game.html` | 修改 | 工具栏 HTML（新增按钮） + 脚本（状态、注入函数、事件绑定） |

## 6. 预期结果

- 工具栏出现「FPS」开关，带高亮激活态。
- 开启后游戏右上角显示实时 FPS；关闭后消失。
- 对流畅度无感知影响。
