# 修复总结：设置面板说明入口 + 说明弹层 + GPU 说明

## 1. 改动

只改 `main.js`（`createLauncherWindow()` 的内联 HTML/CSS/JS），未动 IPC 与配置读写。

| 项 | 说明 |
| --- | --- |
| `.sel-row` / `.info-btn` | 下拉框右侧的「说明」按钮；`min-height:28px`、`padding:4px 12px`，在 `.sel-row`（`align-items:stretch`）里自动撑满下拉框高度 |
| `.help-mask` / `.help-card` / `.help-head` / `.help-body` | 主题化模态弹层：居中卡片、`min(320px,88vw)`、`max-height:70vh`、正文可滚、细滚动条 |

| 说明入口 | Flash 版本、抓包模式两个下拉框右侧各一个；「强制启用 GPU」行右侧一个 |
| `HELP` 文案表 + `openHelp()` / `closeHelp()` | flash / capture / gpu 三份文案；点遮罩、点关闭按钮、按 `Esc` 三种关闭方式 |
| 删除底部说明 | 移除「组织统计抓包说明」「全量抓包说明」两段，内容并入「抓包模式说明」 |

## 2. 过程中发现并修正的问题

1. **GPU 行的「说明」按钮过小**：`.row` 是 `align-items:center`，按钮没有垂直内边距时只有约 16px 高，几乎点不中。实测点击无响应 → 给 `.info-btn` 加 `min-height:28px; padding:4px 12px`。
2. **GPU 行提示换行**：加了说明按钮后标签变窄，原提示「无视驱动黑名单；可能花屏/掉帧，切换后需重启」会折成两行。机制细节已移入说明弹层，行内提示精简为「可能花屏/掉帧，切换后需重启」，恢复单行。
