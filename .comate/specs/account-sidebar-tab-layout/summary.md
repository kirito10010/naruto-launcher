# 账号卡片按钮与顶栏标签排版优化总结

## 已完成

### 账号卡片
- 右侧 4 个操作按钮（打开 / 清除凭证 / 编辑 / 删除）由横排改为 2×2 网格。
- 按钮缩小为 22×22，间距 4px，横向占用从约 108px 降到约 48px。
- 左侧账号信息获得更多宽度，区服下拉框和凭证状态不再被挤。

### 顶栏标签
- 一键启动 / 账号启动的标签区服后缀只保留短名，例如 `1098区 影·起爆` → `1098区`。
- 标签名超出时显示省略号，关闭按钮固定不收缩，多个标签并排时 × 始终可见。
- `.tabs-container` / `.tabs-list` 可随窗口收缩，避免整体溢出裁掉最后一个标签的关闭按钮。
- 标签增加 `title`，hover 可查看完整名称。
