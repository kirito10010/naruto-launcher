# F11 全屏修复 + 账号按区服拆分总结

## 已完成

### F11
- `matchShortcut()` 不再处理 F11，避免和主进程全局 F11 监听同时切换导致「切两次 = 没反应」。
- 全局 F11 监听增加 `input.isAutoRepeat` 保护，按住不会连续切换。
- F11 一次按下只切换一次全屏；退出全屏恢复工具栏。

### 账号按区服拆分
- 账号加载时自动迁移：
  - 一个 QQ 的多个 `credentials` 拆成多条账号；
  - 每条只保留一个 `credential`，删除 `credentials` 映射；
  - 原 ID 给第一个区，其余区使用 `<原ID>-z-<zoneId>`；
  - 账号 ID 冲突自动加序号；
  - 迁移可重复执行，不会重复拆分。
- 新登录抓凭证按 `QQ + zone_id` 匹配：
  1. 同 QQ 同区 → 更新该条；
  2. 同 QQ 还有完全空白的账号 → 填入；
  3. 都没有 → 新建该区账号。
- 清除凭证只清当前条目，保留区服占位（显示「凭证：无」），不会影响同 QQ 其它区。
- 修改账号 QQ 时清空当前条目的凭证。
- 单区账号侧边栏不再显示区服下拉，直接显示区服文本；同 QQ 的每个区是一张独立账号卡。
- 一键启动逻辑不变：遍历账号列表，拆分后自然把同 QQ 的所有区一起打开。
- 迁移前自动备份 `accounts.json.bak`；同区同时存在「已清空占位」和真实凭证时优先保留真实凭证。
- 更多菜单新增「整理旧账号（多区拆分）」，可手动重新读取并执行拆分，用于旧数据没自动处理的情况。
- 如果旧账号只有一条 `credential`、没有 `credentials` 映射，说明其它区从未保存过，无法凭空恢复；需要对每个区登录一次，让凭证自动生成独立账号。
