# F11 全屏修复 + 账号按区服拆分

## 需求

1. 游戏窗口按 F11 全屏异常。
2. 账号改为按「QQ + 游戏区服」分开保存；一键启动时同一个 QQ 的多个区服都能各自启动。

## 问题分析

### F11
F11 同时被两处处理：
- `matchShortcut()` 返回 `fullscreen`，页面收到后发 `toggle-fullscreen` IPC；
- `app.on('web-contents-created')` 里的全局 F11 监听也直接调用 `win.setFullScreen()`。

两处都会切换一次，等于切了两次，表现为 F11 没反应或状态错乱。

### 账号
当前一个 QQ 只存一条账号，区服凭证放在 `account.credentials[zone_id]`；一键启动时每条账号只取 `lastZoneId` 一个区，所以同 QQ 多区只能手动切区逐个启动。

## 方案

### F11
- 从 `matchShortcut()` 移除 F11，只保留主进程全局 F11 监听，避免双触发。
- 全局监听增加 `input.isAutoRepeat` 保护，按住 F11 不会连续切换。

### 账号按区拆分
- 启动加载账号时迁移：把 `credentials` 里的每个区拆成独立账号条目，每条只保留一个 `credential`，删除 `credentials` 映射。
- 迁移后账号 ID 保证唯一：原 ID 保留给第一个区，其余区使用 `<原ID>-z-<zoneId>`。
- 新登录抓凭证时按 `QQ + zone_id` 匹配：
  1. 已有同 QQ 同区 → 更新；
  2. 同 QQ 还有没凭证的条目 → 填入该区；
  3. 都没有 → 新建一条该区的账号。
- 清除凭证只清当前条目对应区，条目保留（显示「凭证：无」）。
- 一键启动沿用「遍历 accounts」，拆分后自然每个区各启动一个标签，不需要额外改启动逻辑。
- 侧边栏单区不再显示下拉，直接显示区服文本；每个区是一张独立账号卡。

## 受影响文件

| 文件 | 修改类型 | 说明 |
| --- | --- | --- |
| `main.js` | 修改 | F11 去重；账号迁移/抓取/清除改为按区拆分 |
| `game.html` | 修改 | 账号说明文案更新（区服独立保存） |

## 边界与异常

- 旧账号只有一个凭证：迁移为一条账号，不产生重复。
- 旧账号有多个凭证：拆成多条，`qqPwd` / `windowName` 复制到每条。
- 迁移可重复执行：拆分后的条目没有 `credentials`，不会再次拆分。
- 账号 ID 冲突时自动追加序号。
- 同一 QQ 多区共用同一个 QQ 登录会话分区，切区不串号；凭证按条目分别保存。
- 一键启动时按账号列表顺序启动所有区。

## 预期结果

- F11 一次按下只切换一次全屏。
- 账号栏同一个 QQ 的每个区各显示一条，一键启动会同时打开所有区服的标签。
