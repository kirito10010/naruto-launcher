# 火影忍者Online启动器

一款基于 Electron 的火影忍者Online页游启动器。内置 Flash 插件、多开、变速、主题切换，并能一键把「组织」相关数据抓包导出成 Excel，方便每周统计。

> 当前版本：**1.2.0**

## ✨ 功能特点

- 🎮 **游戏多开**：多个窗口 / 标签同时运行，**各自独立登录不同账号**（会话互不干扰），支持「一键启动」
- ⚡ **变速**：0.5x / 1x / 2x / 4x / 6x / 10x / 20x，随时切换
- 📊 **组织数据一键导出**：选「组织统计」抓包模式玩一遍，退出后自动生成 6 张 Excel（组织成员 / 组织捐献 / 叛忍数据 / 组织通灵兽 / 忍战数据 + 合并统计总表），零依赖内置生成
- 🔍 **全量抓包**：另一种抓包模式，把本次会话的全部原始网络数据（net-log + HTTP/WS 事件）导出成文件，不生成 Excel，方便后续深度分析
- 🧩 **内置 Flash**：国内版 34.0.0.376 纯净版（默认，已去除重橙的广告与检测组件）+ 国际版 32.0.0.344，免安装 Flash 即可开玩
- 🎨 **主题切换**：薄荷 / 天空 / 樱花 / 暖阳 / 暗夜 五套主题，在设置面板里一键切换
- 🖥️ **清新自绘界面**：启动器与游戏窗口均为无边框自绘标题栏，风格统一
- 🖥️ **F11 全屏**：全屏时自动隐藏顶部栏，再按一次恢复
- 📖 **内置操作说明**：游戏窗口「⋯ → 操作说明」，启动器设置里有抓包流程说明
- 🕹️ **4399 小游戏入口**：附带的独立极简窗口，与火影功能完全解耦
- 🔄 **自动更新**：弹窗展示更新内容 + 下载进度条，内置国内 GitHub 加速线路
- 🧩 **托盘常驻**：关闭启动器窗口即释放其进程，托盘可随时重新打开；退出走托盘菜单
- 🚀 **性能优化**：隐藏标签页不再参与绘制、后台窗口自动降画质，多开更省资源、发热更低

## 📁 项目结构

```
naruto-launcher/
├── main.js              # 主进程（窗口、主题、抓包模式、变速注入、托盘、清理）
├── preload.js           # 账号标签 BrowserView 预加载脚本
├── game.html            # 火影游戏窗口（工具栏、标签、账号侧栏）
├── browser.html         # 4399 等普通网页窗口（极简细条）
├── capture.js           # 抓包层 · CDP（HTTP/WS 事件 → http-*.jsonl）
├── capture-dump.js      # 全量抓包导出（原始文件 → 桌面）
├── export.js            # 组织统计导出（netlog 解析 + TEA 解密 + Protobuf + 数据集）
├── xlsx.js              # 最小 xlsx 生成器（零依赖，手写 ZIP）
├── updater.js           # 自动更新（自定义弹窗 + 国内加速）
├── update.html          # 更新提示弹窗
├── progress.html        # 下载进度弹窗
├── package.json         # 项目配置与打包配置
└── resources/
    ├── flash/           # 内置 Flash 插件（国内版 34.0.0.376 + 国际版 32.0.0.344，x64）
    ├── icons/           # 图标资源
    └── native/          # 变速原生组件（speedctl.exe / speedhook.dll）
```

## 🚀 快速开始

### 开发环境

```bash
npm install
npm start
```

> 若在 VS Code / Comate 的集成终端里启动报错，先清掉环境变量：`$env:ELECTRON_RUN_AS_NODE=$null`（该变量会让 Electron 退化成纯 Node）。

### 打包发布

```bash
npm run build
```

打包输出：`release-v<版本>/NarutoOnlineLauncher-Setup-<版本>.exe`

> ⚠️ 新增页面/脚本后，记得同步 `package.json` 的 `build.files`，否则打包后会缺文件。

## 🎯 使用说明

1. **启动游戏**：点启动器里的「火影忍者Online」
2. **多开**：游戏窗口点 `≡` 打开标签侧栏，或用 `👤` 里的账号列表「一键启动」；也可以从托盘「新建游戏窗口」开多个窗口
3. **变速**：游戏窗口顶部的「变速」下拉
4. **主题 / 抓包模式 / Flash 版本 / 性能开关**：启动器底部「⚙ 设置」
5. **全屏**：游戏窗口按 `F11`，或「⋯ → 全屏」
6. **查看功能说明**：游戏窗口「⋯ → 操作说明」
7. **退出**：托盘图标右键 → 退出（点窗口 × 只是关掉启动器窗口，应用仍驻留托盘）

### 两种抓包模式

在「⚙ 设置 → 抓包模式」里选，**切换后需重启**：

| 模式 | 用途 | 退出后 |
|------|------|--------|
| **组织统计** | 每周统计组织数据 | 桌面「火影组织数据/日期/」生成 6 张 Excel |
| **全量抓包** | 导出全部原始网络数据 | 桌面「火影全量抓包/时间/」生成 net-log + http jsonl + 说明.txt |

组织统计的完整流程见 **[抓包导出使用说明.md](./抓包导出使用说明.md)**。

> ⚠️ 抓包期间会略微卡顿，属正常现象；退出必须走托盘「退出」，否则文件写不完。

## ⚠️ 注意事项

1. **Windows 11 用户**：若变速不可用，请检查「内存完整性」（HVCI）是否开启，开启会影响变速注入
2. **抓包导出**：退出必须走托盘「退出」，否则 netlog 写不完、导不出数据
3. **缓存清理**：清空缓存会清除登录状态，请谨慎操作
4. **Flash 版本**：国内版为去除广告与检测组件的纯净构建；若遇到异常可切回「内置国际版 32.0.0.344」
