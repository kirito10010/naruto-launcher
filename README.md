# 火影忍者Online 启动器

一个面向《火影忍者Online》页游的 Electron 桌面启动器，内置 PPAPI Flash，提供多账号、多标签、凭证登录、抓包导出、变速、窗口透明度、老板键等能力。

## 功能亮点

- **多账号 / 多标签**：同一窗口多标签，账号按「QQ + 区服」独立保存，支持拖动排序、一键启动全部账号。
- **凭证登录**：登录一次自动记住凭证，支持直接进入区服；账号文件使用 Windows DPAPI 加密保存。
- **画面调节**：16:9 渲染分辨率多档（1920×1080 / 1600×900 / 1440×810 / 1280×720），默认 1600×900；窗口按比例锁定、画面铺满；最大化/全屏按 1/8 步进缩放，避免地图接缝。
- **性能选项**：强制启用 GPU、兼容模式（软件渲染）、后台标签限速、进程优先级。
- **实用工具**：变速（0.5x~10x，Ctrl+↑/↓）、窗口透明度（10%~100%，Ctrl+←/→）、老板键 F9、静音、全屏、网址调试。
- **抓包导出**：组织统计（Excel）、全量抓包、题库抓包（忍者检测 / 喵问答）、商城特惠（JSON + 图片 + 技能）。
- **主题与界面**：多套主题、侧边标签栏、界面覆盖层缩放（固定跟随系统 DPI）。
- **绿色运行**：NSIS 安装包，无原生模块依赖。

## 技术栈

- Electron 11.5.0 / Chromium 87（PPAPI Flash 必需，请勿升级）
- 内置 Flash：国内版 34.0.0.376（默认）/ 国际版 32.0.0.344
- 打包：electron-builder 22 + NSIS
- 主进程：`main.js`（单文件）；渲染层：`src/ui/*`；核心逻辑：`src/core/*`；导出：`src/export/*`；抓包：`src/capture/*`

## 开发与构建

```bash
npm install
npm start          # 开发运行
npm run build      # 生成安装包到 release-v<version>/
```

- 运行前如遇 Electron 环境异常，先清除 `ELECTRON_RUN_AS_NODE` 环境变量。
- 本项目目标运行环境只有 Electron，**不要引入需要编译的原生模块或额外运行时**。
- 详细协议/字段说明见 `docs/数据解包说明.md`。

## 更新源

更新采用「多源并发探测」：

1. 并发拉取各源 `latest.yml`，选择版本号最高的源；
2. 版本相同时优先**缤纷云 S4**（`https://naruto-launcher.s3.bitiful.net`）；
3. 缤纷云不可用时，在其余源（GitHub 直连 / 加速代理）中按探测速度选最快。

所有更新源必须为 HTTPS。自建 HTTP 镜像会破坏安装包完整性校验，不纳入自动更新。

## 目录结构

```
main.js                  Electron 主进程（窗口、IPC、更新、抓包、账号、清理等）
src/ui/                  启动器、游戏窗口、更新页、进度页、Flash 画质 preload
src/core/                更新器、在线人数、视频缓存、调试控制台、URL 调试
src/capture/             CDP/net-log 抓包
src/export/              组织统计 / 全量 / 题库 / 商城特惠导出
resources/               Flash、原生依赖、图标、视频
docs/                    数据解包与协议说明
build/                   NSIS 安装脚本
```
