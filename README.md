# 火影忍者Online启动器

一款基于 Electron 的火影忍者Online页游启动器。内置 Flash 插件、多开、变速、主题切换，并能一键把「组织」相关数据抓包导出成 Excel，方便每周统计。

> 当前版本：**1.0.0**

## ✨ 功能特点

- 🎮 **游戏多开**：多个窗口 / 标签同时运行，各自独立登录不同账号，支持「一键启动」
- ⚡ **变速**：0.5x / 1x / 2x / 4x / 6x / 10x / 20x，随时切换
- 📊 **组织数据一键导出**：开启抓包模式玩一遍，退出后自动生成 6 张 Excel（组织成员 / 组织捐献 / 叛忍数据 / 组织通灵兽 / 忍战数据 + 合并统计总表），零依赖内置生成
- 🎨 **主题切换**：薄荷 / 天空 / 樱花 / 暖阳 / 暗夜 五套主题，在设置面板里一键切换
- 🖥️ **清新自绘界面**：启动器与游戏窗口均为无边框自绘标题栏，风格统一
- 🖥️ **F11 全屏**：全屏时自动隐藏顶部栏，再按一次恢复
- 📖 **内置操作说明**：游戏窗口「⋯ → 操作说明」，启动器设置里有抓包导出流程说明
- 🕹️ **4399 小游戏入口**：附带的独立极简窗口，与火影功能完全解耦
- 🔄 **自动更新**：弹窗展示更新内容 + 下载进度条，内置国内 GitHub 加速线路
- 🧩 **托盘常驻**：关闭窗口仅隐藏到托盘，从托盘菜单退出

## 📁 项目结构

```
naruto-launcher/
├── main.js              # 主进程（窗口、主题、抓包开关、变速注入、托盘）
├── preload.js           # 账号标签 BrowserView 预加载脚本
├── game.html            # 火影游戏窗口（工具栏、标签、账号侧栏）
├── browser.html         # 4399 等普通网页窗口（极简细条）
├── capture.js           # 抓包层（net-log + CDP）
├── export.js            # 导出核心（netlog 解析 + TEA 解密 + Protobuf + 数据集）
├── xlsx.js              # 最小 xlsx 生成器（零依赖，手写 ZIP）
├── updater.js           # 自动更新（自定义弹窗 + 国内加速）
├── update.html          # 更新提示弹窗
├── progress.html        # 下载进度弹窗
├── package.json         # 项目配置与打包配置
└── resources/
    ├── flash/           # 内置 Flash 插件（32 / 34 两个版本，x64）
    ├── icons/           # 图标资源
    └── native/          # 变速原生组件（speedctl.exe / speedhook.dll）
```

## 🚀 快速开始

### 开发环境

```bash
npm install
npm start
```

### 打包发布

```bash
npm run build
```

打包输出：`release-v<版本>/NarutoOnlineLauncher-Setup-<版本>.exe`

> ⚠️ 新增页面/脚本后，记得同步 `package.json` 的 `build.files`，否则打包后会缺文件。

## 🎯 使用说明

1. **启动游戏**：点启动器里的「火影忍者Online」
2. **多开**：游戏窗口点 `≡` 打开标签侧栏，或用 `👤` 里的账号列表「一键启动」
3. **变速**：游戏窗口顶部的「变速」下拉
4. **换主题 / 抓包开关 / Flash 版本**：启动器底部「⚙ 设置」
5. **全屏**：游戏窗口按 `F11`，或「⋯ → 全屏」
6. **查看功能说明**：游戏窗口「⋯ → 操作说明」
7. **退出**：托盘图标右键 → 退出（点窗口 × 只是隐藏到托盘）

### 组织数据抓包导出

每周抓一次、自动出表，完整流程见 **[抓包导出使用说明.md](./抓包导出使用说明.md)**。

## ⚠️ 注意事项

1. **Windows 11 用户**：若变速不可用，请检查「内存完整性」（HVCI）是否开启，开启会影响变速注入
2. **抓包导出**：退出必须走托盘「退出」，否则 netlog 写不完、导不出数据
3. **缓存清理**：清空缓存会清除登录状态，请谨慎操作
